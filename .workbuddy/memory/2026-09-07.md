项目概要（后续开发直接复用）：
- 目标：基于大模型的「电商运营报表自动化 Agent」Web 应用。用户用自然语言下指令（如"生成昨日日报/本周周报"），Agent 自动读销售 Excel + 数据库，算指标，生成结构化报表，人工确认后归档导出。
- 架构：前后端分离 B/S。前端 React + TailwindCSS/Ant Design；后端 FastAPI（异步任务）；Agent 框架 LangGraph（规划—执行—反思）；数据处理 Pandas/openpyxl；LLM 走国内直连的 OpenAI 兼容接口；数据库 sqlite3。
- 六个功能模块：任务解析与规划 / 文档与数据自动处理 / 结果生成（Markdown + Word 导出）/ 人工确认与回写 / 评测（≥50 条指令测试集）/ 用户管理。
- 核心指标：GMV、订单量、客单价、转化率、退款率 + 环比。
- 硬指标：指标计算准确率 ≥99%；指令解析准确率 ≥90%；单份日报生成 ≤2 分钟。
- 约束：所有数值必须由计算组件产出，禁止模型直接生成数字；防提示词注入；HTTPS + 存储加密；兼容主流浏览器最新两个版本。
- 数据集来源：天池 https://tianchi.aliyun.com/specials/promotion/Dataset （站内搜"电商 销售数据"）。
- 交付物：WebApp 及代码；PRD / UIUX / 数据库设计 / API 文档 / 测试报告 / 部署运维手册；AI 协作教程；汇报 PPT；报表语料库 + 指令评测集 + 提示词；参数文档（项目说明）。
