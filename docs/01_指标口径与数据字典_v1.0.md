## 2. 维度定义

| 维度 | 取值来源 | 说明 |
|---|---|---|
| 时间 | `order_date` / `order_time` | 日期为 `YYYY-MM-DD` 字符串；日报=单日，周报=周一至周日（自然周），月报=自然月 |
| 市场/店铺 | `country`（43 个取值） | **Country 即"市场/店铺"维度**，支撑"只看英国"类指令；白名单来自库中取值，防注入越权 |
| 商品 | `sku` / `product_name` | `is_product=1` 为真实销售商品（SKU 以 5 位数字开头），排除 POST/D/M/DOT/CRUK/DCGS 等运费、折扣、人工调整条目 |
| 客户 | `customer_id`（缺失=-1） | 仅用于客群拆分，不参与核心 5 指标 |

## 3. 核心指标口径（正式定义）

统一过滤条件（下称**有效商品行**）：`is_refund = 0 AND is_product = 1`

| # | 指标 | 定义（SQL 语义） | 全期基线 | 样例周基线（2010-11-22~28） |
|---|---|---|---|---|
| 1 | **GMV** | `SUM(amount)` where 有效商品行 | 19,642,692.15 GBP | 296,087.91 GBP |
| 2 | **订单量（有效订单）** | `COUNT(DISTINCT order_id)` where 有效商品行 | 41,353 | 691 |
| 3 | **客单价 AOV** | GMV / 有效订单数（同一区间同维度） | 475.00 GBP | 428.49 GBP |
| 4 | **订单转化率**（重定义） | 有效订单数 / 全部生成订单数（区间内全部去重 order_id） | 77.12%（41,353/53,623） | 80.91%（691/854） |
| 5a | **退款率·金额口径** | `SUM(\|amount\|)` where `is_refund=1` / GMV | 7.44%（1,462,797.75/19,642,692.15） | 3.51%（10,389.88/296,087.91） |
| 5b | **退款率·订单数口径** | 退款订单数 / 全部订单数 | 21.79%（11,685/53,623） | 18.38%（157/854） |
| 6 | **环比 MoM** | (本期 − 上一相邻同期)/上一相邻同期；分母为 0 或缺失 → 标注"无可比基期" | — | — |
| 7 | **同比 YoY** | (本期 − 去年同期)/去年同期；数据仅覆盖 2009-12~2011-12，**仅有 2010-12 之后可做同比**，其余标注"无同期数据" | — | — |

> ⚠️ **退款率必须双口径同时呈现**：金额口径与订单数口径实测相差约 3–5 倍（全期 7.44% vs 21.79%），报表中不允许只写"退款率"而不标口径。

> 📌 **退款金额的两种读法（务必区分，不可混用）**
> - **退款金额·绝对值 —— 指标 5a 采用**：`SUM(|amount|) where is_refund=1`，逐笔取绝对值后求和，度量"退款规模"。
>   该口径**按天可加**（`daily_agg` 物化表与区间累加依赖此性质），全期 = **1,462,797.75 GBP**，退款率 7.4470%。
> - **退款净额（带符号）**：`SUM(amount) where is_refund=1` = **−1,462,050.61 GBP**，仅用于 §3.1 GMV 三口径的代数闭合
>   （B − A = 1,462,050.61），**不用于退款率**。
> - 两口径全期相差 **747.14 GBP（0.051%）**，来源：全期存在 1 行 `is_refund=1 且 amount>0` 的记录（正额退款，绝对值口径计入、净额口径被抵消）。
>   示例周无此类记录，故两口径取值同为 10,389.88。
> - **修正说明（2026-09-14 审核）**：v1.0 原文将 5a 写作 `|SUM(amount)|`，与代码实现 `SUM(|amount|)` 不符；
>   此处按实现修正。影响仅限全期分子（1,462,050.61 → 1,462,797.75）、退款率 7.4432% → 7.4470%，
>   **两位小数下同为 7.44%，对外呈现数字不变**。

## 4. 异常波动预警规则（阈值表驱动，待你拍板数值）

| 规则 | 触发条件（建议值） | 报表表现 |
|---|---|---|
| GMV 显著波动 | 环比 ±20% | 标注"显著波动"并列出可能的贡献市场/SKU |
| GMV 重大异常 | 环比 ±50% | 标红 + "重大异常"提示 |

## 6. 边界与特殊处理

1. **数据截止 2011-12-09**：指令涉及"今天/本月/最新"时，若超出数据范围，报表须提示"数据仅更新至 2011-12-09"，禁止外推。
2. **跨年/跨月环比**：按自然周（周一至周日）与自然月切片；跨年环比正常计算，不做特殊平滑。
3. **无数据日**：GMV 记 0 并标注"无交易"；客单价记 0 时须显式标注（避免除零显示为 NaN）。
4. **除零保护**：分母为 0 时返回 `None`，报表渲染为"—"。
5. **市场筛选**：仅接受库中 43 个取值白名单，非法/未提供的市场拒绝并提示（防越权与注入）。
6. **数值来源**：所有指标数值只能来自 `metrics/` 计算组件；大模型仅做表述，**禁止生成任何数值**。

## 7. 指标验证方式（替代人工核算，零人力）

1. **双实现互验**：同一区间与维度，指标分别由 pandas 路径与纯 SQL 路径独立计算，自动比对，**差异必须为 0**；
2. **全量金额断言**：任意维度组合下「分项（商品×市场×日）之和 = 总计」，误差 < 0.01 GBP；
3. **参考结果集**：7 个特征日（普通工作日/周末/月初月末/11 月促销峰值/退款集中/红冲出现/多国混合）自动生成 `data/eval/reference_auto.json`，作为回归 golden，一键复现；
4. 落地 `scripts/qa/cross_check.py`，并入 pytest（D3 完成）。
