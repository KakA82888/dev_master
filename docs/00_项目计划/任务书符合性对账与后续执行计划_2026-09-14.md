## 一、任务书要求（原文摘录，用于对照）

### 1.1 六个具体目标（§2.2）
| # | 目标 | 关键量化要求 |
|---|---|---|
| 1 | 任务解析与规划 | 解析时间范围/店铺范围/报表类型；规划四段任务链；**支持定时任务与批量任务** |
| 2 | 文档与数据自动处理 | 读 Excel + 数据库、字段对齐清洗、5 指标 + 环比；**准确率 ≥99%** |
| 3 | 结果生成 | 指标表 + 同比环比 + 异常说明；**Markdown 与 Word 导出**；**单份日报 ≤2 分钟** |
| 4 | 人工确认与回写 | 预览、修正指标与结论、确认后归档回写、**修改意见沉淀用于优化生成模板** |
| 5 | 评测 | **≥50 条**测试集 + 基准；**解析准确率 ≥90%**；bad case 迭代 |
| 6 | 用户管理 | 注册/登录/任务与历史报告管理；数据安全 |

### 1.2 技术选型（§3.2，9 项）
Python 3.12+ ｜ LLM API（国内直连、OpenAI 兼容）｜ **LangGraph**（参考 Mobile-Agent）｜ Pandas / openpyxl ｜ **报表模板渲染组件、定时调度器** ｜ FastAPI ｜ React ｜ **TailwindCSS / Ant Design** ｜ sqlite3

### 1.3 算法流程（§3.3，5 阶段）
语料准备 → 指标口径与模板构建 → Agent 编排 → 评测优化 → **部署上线**

### 1.4 预期输出（§5）
- **5.1**：可运行 WebApp（Chrome/Firefox/Safari/Edge）及代码；指标口径文档、提示词模板、数据处理脚本
- **5.2**：**AI Coding 中间文件**（PRD、UI/UX、数据库设计、API 接口、测试报告、部署运维手册）；**AI 协作教程**；**PPT**；**报表语料库**；**项目说明（参数文档）**

### 1.5 注意事项（§6）
合规免责 ｜ **内容安全**（数值可回溯、异常如实标注、防提示词注入、敏感内容过滤、**HTTPS 传输**、**数据库存储加密**、**按角色控制权限**）｜ 模型局限（指标必须由组件计算）｜ **浏览器最新两个版本**
