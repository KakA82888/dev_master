### 2.4 Python 指标内核（scripts/metrics/）

| 文件 | 功能（代码做什么） |
|---|---|
| `indicators.py` | **9 个纯函数**：按口径从明细计算 GMV / 有效订单数 / 全部订单数 / 客单价 AOV / 订单转化率 / 退款金额(双口径) / 退款订单数 / 退款率(金额+订单双口径)；无 IO、可单测——所有业务指标的唯一实现 |
| `aggregates.py` | ① `daily_agg` 物化预聚合表（把 103 万行按日压成按日一行，查询提速）；② 周期聚合（日/周/月任意区间求和）；③ 环比/同比工具 |
| `anomaly.py` | 阈值表驱动的异常预警：对比当期 vs 上期，命中 ±20%(GMV)/±15%(AOV)/±50%(退款)/5pp(转化率)/10%(退款率订单) 等阈值 → 只标注"哪个指标异动"，不臆测原因 |
| `test_metrics.py` | 4 项单测：样例周基线（GMV 296,087.91/订单 691/AOV 428.49）、daily_agg 一致性、环比计算、异常标注 |

### 2.5 双轨对账（scripts/qa/）

### 2.6 Agent 编排（scripts/agent/）

| 文件 | 功能 |
|---|---|
| `intent_parser.py` | **意图解析器**：自然语言 → 结构化 Intent{report_type, start, end, country}；识别"昨日/上周/本月"相对日期（锚点=数据最大日期 2011-12-09）、中文绝对区间"11月22日到28日"、43 国市场映射；pydantic 模型输出 |

| `report_builder.py` | Markdown 报告生成：Bundle → 标题/指令引用/核心指标表/异常提示/逐日明细/来源脚注（日报/周报/月报模板） |

## 3. 数据流一图流

```
raw xlsx →[ETL]→ sales_detail(report_agent.db)   ← 唯一事实表
                     │
      intent_parser ← 指令    （S2 规则/LLM 双通道）
      query_executor → metrics/{indicators,aggregates,anomaly}
      orchestrator(LangGraph) → report_builder → markdown 报告
                     │
        FastAPI(S3)：users/reports(app.db) 状态机 + 异步生成
        exporters(S5)：docx/markdown 导出
        React(S4)：工作台轮询 → 预览 → 确认/归档/导出
双轨对账(S1/qa)：pandas vs SQL = 0 → reference_auto.json（≥99% 证据）
```
