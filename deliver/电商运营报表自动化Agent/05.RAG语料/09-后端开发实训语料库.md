## Q: 本项目的后端分层结构是怎样的？

**A:** 分为四层：
1. **接口层 `routers/`**：`auth.py`（注册登录）、`reports.py`（报告全生命周期）
2. **服务层**：`generator.py`（异步生成）、`exporters.py`（导出）
3. **模型层**：`models.py`（ORM：User / Report）、`schemas.py`（请求响应模型）
4. **基础设施**：`config.py`（配置）、`db.py`（引擎与会话）、`security.py`（哈希与 JWT）

`main.py` 负责装配路由、CORS、启动种子账号与前端静态托管。

**标签：** 后端架构, 分层设计, FastAPI, 项目结构

## Q: 报告生命周期有哪些状态？接口如何守卫？

**A:** 状态机：`pending` → `running` → `drafted` → `confirmed` → `archived`，异常进入 `failed`。

接口守卫规则：
- 生成：创建 pending 记录 → 异步任务转 running → 成功转 drafted，失败转 failed
- 确认：仅 `drafted` 可确认，确认后状态转 confirmed 且版本号 +1
- 归档：仅 `confirmed` 可归档
- 导出：`pending`/`running`/`failed` 拒绝导出

**标签：** 状态机, 接口守卫, 报告生命周期, 业务流程

## Q: 为什么生成报告要用异步？如何实现？

**A:** 启用大模型通道后单次生成可能耗时数十秒，同步 HTTP 请求容易超时。实现方式：接口先创建报告记录并立即返回（状态 pending），由后台任务执行生成逻辑并更新状态；前端轮询报告详情获取进度。异常不会静默——失败时状态置为 failed 并记录原因。

**标签：** 异步任务, 长任务, 轮询, 接口设计

## Q: 如何做权限隔离？

**A:** 两层：
1. **认证**：所有报告接口依赖 `get_current_user` 解析 JWT，未授权返回 401
2. **归属校验**：查询报告时同时按 `id` 与 `user_id` 过滤，跨用户访问返回 **404**（而非 403，避免泄露资源存在性）

**标签：** 权限隔离, 越权防护, 404策略, 安全设计

## Q: 密码如何存储？JWT 如何签发？

**A:**
- **密码**：使用 bcrypt 哈希后入库，绝不保存明文；校验时用哈希比对
- **JWT**：登录成功后用密钥（`APP_SECRET_KEY`）与 HS256 算法签发令牌，载荷含用户标识，有效期 24 小时
- **校验**：请求头 `Authorization: Bearer <token>` → 验签 + 校验过期 → 解析出当前用户

**标签：** 密码哈希, bcrypt, JWT, 安全实现

## Q: 为什么测试要用独立的数据库？

**A:** 测试会创建、修改、删除数据。如果直接跑在开发库上，会污染真实数据（本项目曾出现测试用户混入开发库的情况）。做法是通过环境变量 `APP_DB_PATH` 指向独立的测试库（如 `app_test.db`），并在测试前清表，保证测试可重复且不影响开发数据。

**标签：** 测试隔离, 独立数据库, 数据污染, 工程实践

## Q: 后端如何托管前端并实现单端口？

**A:** 启动时检查前端构建产物目录是否存在，存在则把 `dist` 挂载为静态文件服务：

```python
_FRONTEND_DIST = Path(__file__).resolve().parent.parent / "frontend" / "dist"
if _FRONTEND_DIST.exists():
    app.mount("/", StaticFiles(directory=str(_FRONTEND_DIST), html=True), name="frontend")
```

这样访问 `http://host:8000` 即为完整应用，无需额外配置跨域或反向代理。

**标签：** 静态托管, 单端口, 部署简化, 实现细节

## Q: 与 AI 共创后端代码的提示词要点？

**A:** 明确写清**状态守卫与权限规则**，否则 AI 往往只实现"能跑通"的版本：

```
请用 FastAPI 实现后端：
1. 鉴权：bcrypt + JWT，依赖注入获取当前用户
2. 报告接口：生成（异步）/列表/详情/确认/归档/删除/导出
3. 状态守卫：仅 drafted 可确认；pending 禁止导出
4. 权限：跨用户访问返回 404
5. 导出：markdown 原样；word 用 python-docx 按块渲染
6. 挂载前端 dist 实现单端口
7. 配套 pytest（鉴权/生命周期/越权），使用独立测试库
```

**标签：** AI共创, 提示词, 后端生成, 实操方法
