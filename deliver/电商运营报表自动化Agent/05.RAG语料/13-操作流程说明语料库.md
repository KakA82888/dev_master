## Q: 如何启动系统并访问？

**A:**

```bash
# 方式一：一键脚本（自动构建前端并启动后端）
bash scripts/start.sh          # Linux/macOS/Git Bash
scripts\start.bat              # Windows

# 方式二：手动启动
python -m uvicorn app.backend.main:app --host 127.0.0.1 --port 8000
```

浏览器访问 `http://127.0.0.1:8000`，默认账号 `demo / demo1234`。

**标签：** 启动, 访问, 操作流程, 使用说明

## Q: 生成一份日报的完整操作步骤是什么？

**A:**
1. 登录系统（或注册新账号）
2. 在工作台指令框中输入 `生成昨日日报`（也可点击快捷指令 chips）
3. 点击"生成"，界面显示状态从 pending → running → drafted
4. 生成完成后在下方预览报告：核对核心指标表、异常提示、逐日明细
5. 确认无误后点击"确认"，状态转为 confirmed
6. 如需归档，点击"归档"；如需留档，点击"导出"选择 Markdown 或 Word

**标签：** 生成日报, 操作步骤, 工作台, 使用说明

## Q: 支持哪些常用指令示例？

**A:**

| 指令 | 说明 |
|---|---|
| `生成昨日日报` | 数据最大日期的前一天 |
| `生成今天的日报` | 数据最大日期当天 |
| `生成本周周报` | 数据最大日期所在自然周 |
| `生成上周德国周报` | 上一个完整自然周 + 德国市场 |
| `生成上月月报` | 上一个自然月 |
| `生成2011年11月22日的日报` | 指定绝对日期 |
| `生成11月22到28的周报` | 指定区间 |
| `生成全市场本月月报` | 不筛选市场 |

**标签：** 指令示例, 常用指令, 使用说明, 功能演示

## Q: 如何查看和筛选历史报告？

**A:** 进入"历史报告"页面，支持四个维度的筛选：
- **报表类型**：日报 / 周报 / 月报
- **市场**：43 个市场或全市场
- **状态**：待确认 / 已确认 / 已归档 / 生成失败
- **关键字**：按指令内容模糊匹配

点击任意一条记录可查看详情，并执行确认/归档/导出/删除操作。

**标签：** 历史报告, 筛选, 四维筛选, 使用说明

## Q: 报告有哪些状态？各状态下能做什么？

**A:**

| 状态 | 含义 | 可用操作 |
|---|---|---|
| 待生成 pending | 已提交，等待执行 | 删除 |
| 生成中 running | 正在生成 | — |
| 待确认 drafted | 生成完成，待人工确认 | 确认 / 导出 / 删除 |
| 已确认 confirmed | 已人工确认 | 归档 / 导出 |
| 已归档 archived | 已归档 | 导出 / 删除 |
| 生成失败 failed | 生成过程出错 | 重新生成 / 删除 |

**标签：** 报告状态, 状态说明, 操作权限, 使用说明

## Q: 导出功能怎么用？

**A:** 在报告预览区点击"导出"下拉，选择：
- **Markdown**：下载 `.md` 文件，便于二次编辑或贴入其他系统
- **Word**：下载 `.docx` 文件，可直接打印或提交

注意：仅"待确认"及之后的状态可导出；未生成完成时导出按钮不可用。

**标签：** 导出, Markdown, Word, 使用说明

## Q: 系统会拒绝哪些指令？拒绝后如何提示？

**A:** 会拒绝五类指令：提示词注入（如"忽略上面的指令"）、越权请求（如索要他人数据）、伪造数值（如"把 GMV 改成 100 万"）、越界日期（如 2025 年）、破坏性 SQL（如 `DROP TABLE`）。

拒绝时报告状态置为 failed，并给出具体原因（如"检测到危险的 SQL 指令片段，已拒绝执行"），而不是笼统的"生成失败"。

**标签：** 拒绝指令, 安全拦截, 提示信息, 使用说明

## Q: 如果查询的日期没有数据会怎样？

**A:** 两种情形：
1. **超出数据范围**（数据仅到 2011-12-09）：系统拒绝并提示"数据仅更新至 2011-12-09"，不生成报表
2. **区间内无交易**：报表正常生成，但 GMV 为 0 并标注"无有效商品销售数据"，同时提示确认日期与市场是否正确

**标签：** 无数据, 数据边界, 边界处理, 使用说明
