## Q: 部署前需要准备什么？

**A:** 四项：
1. **运行环境**：Python 3.12+（服务器无需 Node.js，前端产物已内置在部署版）
2. **数据文件**：事实表 `report_agent.db`（约 203 MB）放到 `data/processed/`
3. **配置文件**：从 `.env.example` 复制为 `.env`，填写密钥与账号
4. **依赖安装**：`pip install -r requirements.txt`

**标签：** 部署准备, 环境要求, 数据文件, 部署运维

## Q: 如何把服务部署为常驻进程？

**A:** 使用 systemd（Linux）托管，实现开机自启与崩溃自动重启：

```ini
# /etc/systemd/system/report-agent.service
[Unit]
Description=Report Agent Service
After=network.target

[Service]
WorkingDirectory=/opt/report_agent/backend
ExecStart=/opt/report_agent/backend/.venv/bin/python -m uvicorn app.backend.main:app --host 127.0.0.1 --port 8000
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now report-agent
systemctl status report-agent
```

**标签：** systemd, 常驻服务, 自动重启, 部署运维

## Q: 生产环境必须修改哪些配置？

**A:** 三项：
1. `APP_SECRET_KEY`：JWT 签名密钥，必须改为高强度随机值（默认值为开发占位）
2. `SEED_PASSWORD`：种子账号密码（默认 `demo1234`），生产必须修改或删除种子账号
3. `LLM_API_KEY`：如启用大模型通道，使用独立的、可轮换的生产密钥

**标签：** 生产配置, 密钥管理, 安全加固, 部署运维

## Q: 系统有哪些数据需要备份？

**A:**

| 对象 | 备份方式 | 频率 |
|---|---|---|
| 应用库 `app.db` | 直接复制文件（SQLite 单文件） | 每次发版前 |
| 事实表 `report_agent.db` | 可由原始数据 + ETL 重建，一般无需备份 | 视需要 |
| `.env` | 妥善保管，不进仓库 | 变更时 |
| 生成的报告文件 | 随应用库或独立目录备份 | 按需 |

恢复流程：停止服务 → 覆盖 `app.db` → 启动服务（表结构自动创建）。

**标签：** 备份, 数据恢复, 运维管理, 部署运维

## Q: 如何做健康检查与监控？

**A:** 三个层次：
1. **健康检查接口**：`GET /api/health` 返回 `{"status":"ok"}`，可接入监控系统定时探测
2. **冒烟脚本**：`python scripts/eval/smoke_http.py` 验证完整链路（鉴权/生成/确认/导出），幂等可重复执行
3. **日志**：后端日志用 `journalctl -u report-agent -f` 查看；Nginx 错误日志 `/var/log/nginx/error.log`

**标签：** 健康检查, 监控, 冒烟脚本, 部署运维

## Q: 如何升级系统？

**A:** 三步：
1. 备份 `app.db`
2. 替换 `backend/` 代码与 `static/` 前端产物（数据文件与 `.env` 不动）
3. 重启服务（`systemctl restart report-agent`）

升级后建议执行 `pytest -q` 与 `smoke_http.py` 验证。

**标签：** 升级, 发版流程, 回归验证, 部署运维

## Q: 生产环境还有哪些安全建议？

**A:** 五项：
1. 启用 HTTPS（Nginx 反代 + 证书），不直接暴露后端端口
2. `.env` 文件权限设为 600，不纳入版本库
3. 数据库文件限制访问权限；敏感环境可用 SQLCipher 加密
4. API Key 定期轮换；怀疑泄露立即吊销
5. 限制访问来源（内网或白名单），并保留访问日志

**标签：** 安全加固, HTTPS, 权限控制, 部署运维

## Q: 常见运维操作速查？

**A:**

```bash
# 启动 / 停止 / 重启
systemctl start|stop|restart report-agent

# 查看状态与日志
systemctl status report-agent
journalctl -u report-agent -f

# 健康检查
curl http://127.0.0.1:8000/api/health

# 全量测试
python -m pytest -q

# 重建语料库
python scripts/build_corpus.py

# Nginx 配置检查与重载
nginx -t && systemctl reload nginx
```

**标签：** 运维命令, 速查表, 日常运维, 部署运维
