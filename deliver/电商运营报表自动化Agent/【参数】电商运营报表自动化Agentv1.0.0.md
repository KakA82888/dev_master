# AI共创开发电商运营报表自动化Agent V1.0.0

## 一、案例资源

包含1个应用、1份案例PPT、9份实训指导书（7份实训 + 2份附录）、1份代码、18份RAG语料，1份RAG提示词。

***

## 二、概要

通过学习本案例，可了解电商运营报表自动化 Agent 的系统架构与技术实现，掌握**自然语言指令解析、指标体系与数据清洗、Agent 任务编排、报表自动生成与人工确认回写**的完整开发方法，为后续相关课程学习及将来从事数据智能、办公自动化领域的工作奠定基础。

电商运营团队每天需要从销售数据中汇总 GMV、订单量、客单价、退款率等指标并撰写日报周报，人工制表重复劳动大、统计口径容易出错，促销节点数据量激增时报表产出常常滞后于决策。本案例结合大语言模型与 Agent 任务规划技术，实现"自然语言输入 → 意图解析 → 指标计算 → 波动分析 → 报告生成 → 人工确认 → 归档导出"的全流程自动化，把重复性报表工作交给智能体完成。

**本案例的核心特色是采用 AI 共创开发模式**，即在产品研发过程中借助大语言模型等 AI 工具辅助完成文档撰写、方案设计、代码开发与测试评测。这种方式可大幅提高开发效率、减少重复劳动，让学习者专注于理解业务逻辑与技术原理，快速掌握从需求分析到部署运维的完整开发流程。

理论教学6学时，实践教学6学时，总计12学时。

## 四、目标

基于销售明细数据，实现从自然语言指令到结构化经营报表的自动生成：自动解析时间范围、市场与报表类型，按统一口径计算 GMV、订单量、客单价、订单转化率、退款率（双口径）及环比，标注异常波动，生成含指标表与逐日明细的日报/周报/月报，支持人工确认与 Markdown/Word 导出。

***

## 五、流程

1. **需求与口径设计**：梳理业务需求，定义指标口径（GMV 口径、转化率重定义、退款率双口径）与异常波动阈值，形成唯一口径文档。
2. **数据与指标内核**：清洗原始销售数据（去重、负单价、客户缺失、跨表重叠等规则），构建唯一事实表，实现纯函数指标模块与自动化双轨对账。
3. **Agent 编排**：实现"意图解析 → 取数计算 → 波动校验 → 报告生成"状态机；安全网关前置拦截注入/越权/伪造数值/越界指令；大模型失败自动回退规则通道。
4. **服务与界面**：FastAPI 提供鉴权与报告生命周期接口（含异步生成与导出）；React 实现工作台、报告预览、人工确认、归档与历史管理。
5. **评测与部署**：构建指令评测集评测解析准确率与指标一致性，接入大模型通道做双通道对照，完成部署与运维文档。

***

## 六、技术点

- **前端技术**：React 18、TypeScript、Vite 5、自建设计系统（Design Tokens）
- **后端技术**：FastAPI、Python 3.12+、SQLAlchemy 2、Pydantic 2、JWT 鉴权
- **Agent 编排**：LangGraph 状态机（plan → execute → reflect → build）
- **数据处理**：pandas、openpyxl；SQLite（事实表 + 应用库物理隔离）
- **大模型**：OpenAI 兼容接口（SiliconFlow / DeepSeek），仅做意图解析，禁止生成数值
- **报告导出**：python-docx（Word）、Markdown
- **质量保障**：pytest、pandas/SQL 双轨对账、指令评测集（90 条）
- **架构设计**：前后端分离、RESTful API、单端口静态托管、Nginx HTTPS 反代

***

## 七、应用功能

1. **自然语言报表生成**：
   - 支持"生成昨日日报 / 本周德国周报 / 上月月报"等指令
   - 自动识别相对时间（昨日/上周/本月）、绝对日期与区间、43 个市场
   - 信息不足时主动澄清，超范围时明确拒绝并提示数据截止日期

2. **指标计算与异常分析**：
   - 核心指标：GMV、有效订单数、客单价、订单转化率、退款率（金额/订单数双口径）
   - 环比计算与异常阈值标注（GMV ±20%/±50%、AOV ±15%、转化率 5pp 等）
   - 数值全部由计算组件产出，可回溯至事实表与清洗规则

3. **报告与导出**：
   - 报告含核心指标表、异常提示、逐日明细与数据来源脚注
   - 支持 Markdown 与 Word（.docx）导出

4. **人工确认与归档**：
   - 报告状态机：pending → running → drafted → confirmed → archived
   - 确认后归档，历史报告支持按类型/市场/状态/关键字筛选

5. **安全与用户管理**：
   - 用户注册登录（JWT）、报告归属校验（跨用户访问返回 404）
   - 安全网关拦截提示词注入、越权、伪造数值、越界日期、破坏性 SQL
