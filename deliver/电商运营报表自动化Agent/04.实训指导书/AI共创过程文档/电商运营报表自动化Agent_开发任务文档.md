## 三、风险清单

| # | 风险 | 影响 | 应对 |
|---|---|---|---|
| R1 | 指标口径反复变更 | 数值全部返工 | 口径文档先行并签字确认，变更走记录 |
| R2 | 评测"自己出题自己判" | 准确率不可信 | 建留出集 + 双通道对照 + 业务负责人抽查 |
| R3 | 大模型不稳定/超时 | 演示失败 | 双通道设计，失败自动回退规则通道 |
| R4 | 安全漏洞（注入/越权） | 数据风险 | 安全网关前置 + 安全自查用例 |
| R5 | 文档滞后于代码 | 交付不完整 | 每阶段结束即补文档并做缺口审计 |
| R6 | 前端未真机验证 | 演示翻车 | 交付前人工走查核心流程 |

## 四、关键路径

```
S1 指标内核（口径 → 清洗 → 指标 → 双轨对账）
   → S2 Agent 编排 → S3 后端 → S4 前端 → S5 导出
   → S6 评测（硬指标证据） → S7 部署 → S9 文档与交付
```

> 关键路径上的任何延误都会推迟里程碑；文档与语料可在开发阶段并行准备。
