## 1. 变更内容

| | 内容 |
|---|---|
| 任务书原要求（§3.3） | 从天池数据集专场检索并下载电商销售数据（`https://tianchi.aliyun.com/specials/promotion/Dataset`，站内搜索"电商 销售数据"），整理为标准销售明细表 |
| 实际采用 | **UCI Machine Learning Repository · Online Retail II**（`data/raw/online_retail_II.xlsx`） |
| 数据属性 | 2 sheet Excel；2009-12 ~ 2011-12；原始 1,067,371 行；英国跨境批发/零售；43 个市场；含订单时间、金额、退款标记（C 开头发票/负数量）、商品、客户等字段；CC BY 4.0 |

## 2. 变更理由

1. **字段形态匹配**：本项目核心指标含「退款率」（区别于普通 GMV 报表），必须使用同时具备 **订单金额 + 退款标记 + Excel 可读 + 多周期时间** 的明细数据；UCI Online Retail II 是公开数据集中唯一完整满足的数据集，可真实计算退款率。
2. **可复现性**：UCI 无注册/审核门槛、授权清晰（CC BY 4.0），答辩、复算、评测均可一键复现；天池对应数据集需平台注册与授权申请，且字段口径不统一。
3. **口径落地已验证**：变更后的清洗规则 R1–R6 与全部指标基线（GMV 19,642,692.15 GBP 等）已通过自动化双轨对账（pandas/SQL 差异 = 0），验证充分。
