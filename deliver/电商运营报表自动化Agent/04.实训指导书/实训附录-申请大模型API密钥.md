# 实训附录 申请大模型API密钥

## 一、实训目标

1. 掌握大模型开放平台的开通与 API Key 创建流程
2. 学会把 API Key 安全地配置到项目中（`.env` + 忽略规则）
3. 理解"密钥不入库、不外传"的安全要求
4. 能够验证密钥是否生效（大模型通道是否可用）

## 二、实训内容

### 1. 背景知识

- **API Key**：调用大模型接口的凭证，等同于账号密码，泄露会导致费用损失与数据风险。
- **OpenAI 兼容接口**：多数国内平台提供与 OpenAI 一致的接口格式，因此只需改 `base_url`、`api_key`、`model` 三项即可切换供应商。
- **双通道设计**：本项目即使不配置 API Key 也能运行（走规则通道），配置后启用大模型通道。

### 2. 项目结构

```
01.code/
├── .env.example            配置模板（可入库）
├── .env                    实际配置（不入库，已被 .gitignore 忽略）
└── scripts/agent/llm_client.py   大模型调用封装
```

## 三、实训步骤

### 步骤1：注册并开通大模型服务

**操作：**
以 SiliconFlow（硅基流动）为例：

1. 打开官网，注册并登录账号；
2. 进入控制台，完成实名认证（部分平台调用前需要）；
3. 在"模型广场"确认目标模型可用（本项目使用 `Pro/deepseek-ai/DeepSeek-R1`）。

> 【截图位】建议插入：注册/登录截图

**操作结果：**
- 账号创建完成，可进入控制台。

**操作验证：**
- 控制台可正常访问，账户余额/免费额度可见。

**操作说明：**

1. **为什么需要实名/额度？**
   大模型接口按 token 计费，实名与额度是平台风控要求。

2. **如何选择模型？**
   意图解析这类结构化任务不需要推理型模型；推理模型（如 R1）延迟高、成本高。生产建议选用更快的对话模型（如 DeepSeek-V3），切换只需改一行配置。

### 步骤2：创建API Key

**操作：**

1. 进入控制台的"API 密钥"页面；
2. 点击"新建 API 密钥"，命名（如 `report-agent-dev`）；
3. **立即复制并妥善保存**（多数平台只显示一次）。

> 【截图位】建议插入：创建 API Key 截图

**操作结果：**
- 获得形如 `sk-xxxxxxxx` 的密钥字符串。

**操作验证：**
- 在密钥列表能看到新建的 Key 与其创建时间。

**操作说明：**

1. **密钥安全**
   - 不要粘贴到聊天工具、截图或文档中；
   - 不要提交到代码仓库；
   - 一旦怀疑泄露，立即到控制台**删除并重新创建**。

2. **多环境管理**
   开发/测试/生产使用不同 Key，便于分别限额与吊销。

### 步骤3：配置到项目并验证

**操作：**

```bash
# 1) 复制模板
cp .env.example .env

# 2) 编辑 .env，填写三项（示例）
# LLM_BASE_URL=https://api.siliconflow.cn/v1
# LLM_API_KEY=sk-你的密钥
# LLM_MODEL=Pro/deepseek-ai/DeepSeek-R1
# LLM_MODE=llm
```

验证：

```bash
# 单条指令冒烟（启用大模型通道后响应会明显变慢，属正常）
python -c "
import os; from dotenv import load_dotenv; load_dotenv()
from scripts.agent.llm_client import llm_parse_intent
print(llm_parse_intent('生成昨日日报'))
"
```

**操作结果：**
- 返回结构化的 `Intent`（report_type / start / end / country）。

**操作验证：**
- 返回结果中的日期与预期一致；
- 若不配置 Key 或 Key 无效，系统应自动回退规则通道且不报错。

**操作说明：**

1. **`.env` 必须被忽略**
   确认 `.gitignore` 中包含 `.env`；提交前用 `git status` 检查，避免误提交。

2. **失败回退的价值**
   答辩或演示现场网络异常时，系统仍能正常出报，不会中断。

## 四、注意事项

1. **密钥保密**：`.env` 权限最小化；不在日志中打印密钥；不与他人共享。

2. **费用控制**：设置额度上限；意图解析这类任务优先用便宜快速的模型。

3. **密钥轮换**：定期更换；怀疑泄露立即吊销重建。

4. **网络依赖**：大模型通道需要外网；内网环境请使用规则通道或配置代理。

5. **实训管理**：每位学员使用自己的 Key，避免共用导致额度与责任不清。
